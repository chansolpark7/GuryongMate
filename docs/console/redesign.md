# console v2 — 관제 대시보드 개편 (2026-10-11)

지금 대시보드(`infra/gateway/console/`, 명세 `README.md`)는 기능은 다 되지만 **정보가 너무 많고 개발 도구처럼 보인다**
(오른쪽 패널에 시각·안전·위치·이벤트가 길게 쌓이고, `L3`·`delivered`·`mock 데이터`·`scripted` 같은 내부 용어가 그대로 나온다. 지도에는 안전한 구역까지 초록 원 11개).
발표 화면(왼쪽 앱 에뮬레이터, 오른쪽 대시보드)에서 **청중이 한눈에 이해하고, 발표자가 생각 없이 조작**할 수 있게 다시 짠다. 백엔드 API·동작은 바꾸지 않는다.

## 1. 원칙
1. **지도가 주인공.** 지도를 화면 가득, 조작은 지도 위 떠 있는 작은 카드로.
2. **보이는 건 지금 중요한 것만.** 안전(초록)한 것은 그리지 않는다. 위험·주의·피할 구역·사용자·일정만.
3. **한 가지 조작 = 한 가지 동작.** 시간은 막대를 끌어서, 위치는 점을 끌어서, 날씨는 아이콘을 눌러서.
4. **사람 말로.** 내부 코드 대신 문장과 아이콘. 개발자 정보는 [개발자 정보] 서랍 안으로.
5. **앱과 같은 디자인 언어.** 색·모서리·그림자를 앱 토큰(`app/lib/core/theme/app_theme.dart`)에 맞춘다.

### 2.1 상단 바 (한 줄, 상태만)
- 가상 시각(크게, 초 단위). 실제 시각과 다르면 작은 "가상" 표시만 (차이 분 숫자는 툴팁).
- 날씨 칩: 아이콘 + 이름 + 끝 시각 (`⛈ 폭풍 ~17:00`, `☀️ 평상시`, `📡 실시간 DT`).
- 여행 칩: `여행 전` / `🚶 동행 중 · {지금 상태 문장}` (예: "가옥거리 머무는 중", "과메기문화관으로 이동 중 · 15분 늦음").
- 오른쪽 👤 메뉴: 사용자·계획 선택, 설정(서버·관리 토큰), **계정 초기화**(§3), 개발자 정보, 로그아웃.
- 연결 문제·LLM 공급자·관리 토큰 없음은 정상일 때 숨기고 **문제가 있을 때만** 상단에 노란 띠로.

### 2.2 지도
- 기본 레이어: 일정(번호 마커 + 구간 경로선, 지난 일정은 흐리게, 지금 머무는 곳 강조), 사용자 위치(파란 점, **끌어서 놓으면 순간이동**), **주의·위험인 구역만** 색칠, 피할 구역 빗금.
- 기본으로 숨김(레이어 버튼에서 켬): 안전한 구역, 센서 전체(센서는 등급이 오른 것만 기본 표시), 방파제 CCTV 집계.
- 일정 마커를 누르면 작은 말풍선: 이름 · 예정 시각 · 상태 + 큰 버튼 두 개 **[여기로 걸어가기]** **[여기서 머물기]** (머물기 시간은 버튼 옆 작은 선택 3/10/30분). 차로 가기·순간이동은 `⋯` 안.
- 지도 빈 곳을 누르면: [여기로 이동] [걸어가기] 두 개만.
- 걸어가는 중에는 지도 위 작은 진행 카드: "가옥거리로 걷는 중 · 3분 남음 [멈춤]".
- 이벤트가 생기면 그 자리에 2~3초 말풍선 (지금 기능 유지).
- 여행 전이면 위치 조작 대신 지도 하단 중앙에 큰 버튼 **[여행 시작]** (계획 날짜가 아니면 "계획 날짜(10/10)로 이동 후 시작" 한 버튼으로).

### 2.3 하루 타임라인 (하단, 시간과 날씨를 한 곳에서)
- 가로축: 계획 날짜의 `day_start - 2시간` ~ `day_end + 2시간` (기본 10~20시). 일정 블록(번호·이름, 상태 색), **날씨 구간 띠**, **지금 시각 바늘**.
- **바늘을 끌면 가상 시각 이동** (놓을 때 한 번 `PUT /safety/sim {now}`). 뒤로 끌면 "이전 위치보다 이른 시각이에요" 확인 (README §2.2).
- 날씨 띠: 날씨 카드에서 종류를 고른 상태로 **띠 위를 끌면 그 구간 추가**, 구간을 누르면 [삭제] [끝 시각 바꾸기]. 겹침·종류 규칙은 README §7.5 그대로.
- 버튼: `+10분` `+30분` `▶ 재생`(가상 시각을 배속으로 흘림 — 위치 전송 없이 시간만, 배속 ×10/×20/×60) `지금(실제)으로`.
- 날짜가 계획 날짜가 아니면 축 위에 "계획 날짜로" 한 버튼.

### 2.4 날씨 카드 (지도 위 오른쪽 아래, 접을 수 있음)
- 맨 위 토글: **실시간 DT** ↔ **가상 시나리오**. 실시간이면 아래는 흐리게 + "지금 구룡포 실제 데이터 (E-UM 센서·CCTV·기상청)".
- 큰 아이콘 버튼 5개: ☀️ 평상시 · 🌧 비 · 🌊 침수 · 💨 강풍 · ⛈ 폭풍. 누르면 "지금부터 [1시간] [2시간] [계속] / 끝 시각 지정" 작은 선택 → 구간 추가.
  (`wind_tomorrow` 같은 프리셋 이름은 숨긴다. 내일 강풍은 타임라인 날짜를 내일로 넘겨 구간을 그리면 된다.)
- 한 줄 요약: "특보 3건 · 위험 구역 3곳" 또는 "특이사항 없음". 펼치면 특보 목록·12시간 위험 신호 (지금 내용).
- [안전 점검 지금] 은 기본 숨김 — 날씨를 바꾸면 자동으로 점검 + 틱 (지금 "바꾸면 바로 반영" 동작을 기본·고정으로). 개발자 정보에서 끌 수 있게.

### 2.5 오른쪽 피드 "지금 일어난 일" (좁게, 접을 수 있음)
- 이벤트를 **사람 문장 카드**로: 아이콘(📍 도착, 👋 출발, ⏰ 늦어짐, ⚠️ 위험, ✅ 해제, 🚧 위험 구역, 🏁 시작·종료) + 시각 + `message` 한 줄.
- Agent 선제 턴(레벨 3)은 보라색 테두리 + "✨ 구룡메이트가 먼저 말을 걸었어요" 한 줄 (제안 번호·전송 상태는 개발자 정보).
- `L0~L3`, `delivered/queued/suppressed` 같은 표기는 기본 숨김. 대기(queued)·실패(failed)만 작은 회색/빨강 글자로 ("곧 전달", "전달 실패").
- 최근 8개만, 나머지는 [더 보기]. planner 안전 경고 목록은 개발자 정보로.

### 2.6 개발자 정보 서랍 (👤 메뉴 → 개발자 정보)
지금 화면에 있던 상세를 모두 여기로: 서버·LLM 공급자, 데이터 소스 상태, 원시 이벤트(레벨·상태·agent id·payload), planner 안전 경고, 위치 전송 결과(accepted/ignored), 자동 점검·틱 스위치, 배속 기본값.

## 3. 계정 초기화 (새 기능)
👤 메뉴 → **계정 초기화** 대화상자. 세 가지를 분리해서 보여준다:

| 버튼 | 하는 일 | API |
|---|---|---|
| **내 데이터 지우기** | 이 계정의 계획·대화·여행 기록·메모리·가이드 노트 삭제 (계정·로그인은 유지) | 계획마다 `POST /trip/plans/{id}/end`(실패 무시) → `DELETE /planner/me`, `DELETE /trip/me`, `DELETE /docent/me`, `DELETE /agent/me` (각 서비스 탈퇴용 API, 204). 하나가 실패하면 어느 것이 실패했는지 보여주고 나머지는 계속 |
| **데모 시작 상태로** | 위 삭제 + 가상 시각 10/9 10:00, 평상시(시간표 비움) + 빈 계획 '엄마랑 구룡포'(10/10 12:30~18:00) + 대화 세션 | `run_demo.py` 의 `prep`(기본 `--plan chat`)과 **같은 결과**. 계획 값은 `scripts/trip/scenes/scene4_safety.json` 의 `plan` 을 그대로 쓴다 (페이지에 사본을 두면 함께 고칠 곳이 생기니, 빌드 없이 쓸 수 있게 `infra/gateway/console/demo_plan.json` 으로 복사하고 둘이 같은지 확인하는 테스트·스크립트 한 줄을 남긴다) |
| **환경 원래대로** | 실제 데이터 + 실제 시각 + 시간표 비움 (서버 전체 공용) | 🔒 `PUT /safety/sim {"source":"live","reset_clock":true,"timeline":[]}` (`switchable=false` 면 가능한 것만) |

- 앞의 두 개는 **로그인한 사용자 자신의** 데이터만 지운다 (관리 토큰 불필요). 대화상자에 지금 계정 아이디·계획 수를 보여주고, 아이디를 직접 입력해야 [지우기]가 켜진다.
- "환경 원래대로"는 "같은 서버를 쓰는 모든 사람에게 적용돼요" 경고를 붙인다. 발표·리허설 끝에 쓰는 버튼이다.
- 각 서비스 `DELETE /me` 가 무엇을 지우는지 실제 코드(`backend/app/*/router.py` `delete_my_data`)로 확인하고, 계정 탈퇴(`DELETE /users/me`)는 **절대 부르지 않는다.**
- 지운 뒤 화면 상태(선택 계획·이벤트 커서·걷기 진행)를 비우고 다시 불러온다.

## 4. 시각 디자인
- 색: 앱 토큰 — primary `#2F6BFF`, ai `#7B61FF`(Agent·✨), success `#12A150`, warning `#D97706`, danger `#E5484D`, text `#111827`/`#4B5563`/`#8B95A1`,
  line `#E8EBEF`, background `#F5F6F8`, surface `#FFFFFF`. 위험 단계 색은 success/warning/danger 와 각각의 Soft 색.
- 떠 있는 카드: 흰 배경, 모서리 14px, 그림자 `0 8px 24px rgba(17,24,39,.14)`. 버튼 높이 36px 이상(발표 중 클릭 쉽게), 아이콘 버튼 40px.
- 글꼴: 시스템 한글 글꼴 스택(`Pretendard, "Apple SD Gothic Neo", "Malgun Gothic", system-ui, sans-serif`) — 외부 글꼴 다운로드 없음.
- 지도 타일은 지금처럼 OSM. 대비를 낮추는 옅은 필터(채도 ↓) 정도로 정보 레이어가 돋보이게.
- 다크 모드는 지금 것 유지(토큰만 바꿔서).
- 960px 폭(발표 시 에뮬레이터와 나란히)에서: 오른쪽 피드는 접힌 상태로 시작(아이콘 + 새 이벤트 수 배지), 타임라인·날씨 카드는 그대로.

## 5. 유지할 것 / 하지 않을 것
- 유지: README §1 구성(정적 페이지·게이트웨이 서빙·인증·관리 토큰), §4 함정 처리(시계 캐시 대기, `recorded_at` 단조, 도착 90초, 틱 `?now=`), 폴링 주기, 다중 탭 안전.
- 하지 않음: 백엔드 API 추가·변경, 대화·제안 승인, 계획 편집, 앱(`app/`) 변경.

## 6. 확인
- 개발 스택(worktree, 다른 `API_PORT`, `SAFETY_SIM_ENABLED=true`, `AGENT_PROVIDER=scripted`)에서:
  1. 👤 → 계정 초기화 → **데모 시작 상태로** → 계획 1개(빈 '엄마랑 구룡포'), 가상 10/9 10:00, 평상시. `run_demo.py --from s1_chat` 이 그대로 이어지는지.
  2. 타임라인 바늘을 10/10 12:20 으로 → [여행 시작] → 일정 ① 마커 [여기로 걸어가기] → [여기서 머물기 3분] → 피드에 📍 도착.
  3. 날씨 ⛈ 폭풍 "끝 시각 17:00" → 타임라인에 띠, 지도에 위험 구역·피할 구역, 피드에 ⚠️ + ✨. 바늘을 17:05 로 → 지도에서 색이 사라짐.
  4. **내 데이터 지우기** → 계획 0개, 피드 비움. **환경 원래대로** → 📡 실시간 DT, 실제 시각.
  5. 운영 게이트웨이(Caddyfile.prod) + 관리 토큰 없음: 날씨·시간 조작 시 "관리 토큰 필요" 띠, 내 데이터 지우기는 동작.
- 캡처: 1440·960 폭 각각 — 여행 전, 동행 중 평상시, 폭풍 중, 계정 초기화 대화상자 → `docs/console/review/v2_*.jpg`. 지금 캡처와 나란히 비교할 수 있게.
- `run_demo.py --auto --speed 0` 22/22 그대로 (대시보드는 run_demo 와 독립이지만 공용 파일을 건드렸다면).
- 끝나면 `docker compose down`.
