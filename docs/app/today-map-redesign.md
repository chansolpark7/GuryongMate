# Today · Map 역할 나누기 (2026-10-11 결정)

동행 모드에서 Today(14·15)와 Map(07·28)이 같은 지도·같은 경로를 보여주고, Today 의 핀·일정 행·[경로 전체]가 모두 Map 탭으로 넘겨 역할이 겹친다.
Map 의 아래 카드는 손잡이 그림만 있고 끌 수 없으며, [길 안내] 버튼은 커다란데 바뀌는 게 거의 없다. 또 여행 시작~첫 도착 전에는 Today 패널에 남은 일정 목록이 안 보인다.
아래처럼 나눈다. 백엔드 API 는 바꾸지 않는다.

## 1. 역할

| | **Today = 지금 여행** (진행·안내) | **Map = 둘러보기·자세히** (탐색·상세·안전) |
|---|---|---|
| 지도 | 오늘 경로, 내 위치, 지나온 구간 회색, 지금·다음 강조, 위험 구역, 길 안내선 | 날짜별 경로, 주변 관광지 레이어, 위험 구역·우회 길. **동행 중이면 내 위치·지나온 구간 회색·지금/다음 강조도** (명세 07 "동행 중이면 현재 위치 점 + 다녀온 구간 회색") |
| 장소 누르기 | 그 자리 작은 창 (§2.2). **탭 이동 없음** | 아래 시트에 그 장소 (§3) |
| 아래 | 지금 / 다음 / 남은 일정 목록 (§2.3) | 끌어 올리는 시트: 접힘 = 요약, 펼침 = 상세 (§3) |
| 서로 가기 | Today 에 작은 [전체 지도] 버튼 하나 → Map (지금 날짜·선택 유지) | 하단 탭 |

## 2. Today

### 2.1 길 안내 — 이동 중 자동 + 작은 토글
- **자동 켜짐**: 다음 장소로 이동 중(`current.state == moving`)이거나, 첫 장소 전(`idle`, 아직 아무 데도 안 감)에 위치가 있으면 다음 장소로 안내 (상단 안내 카드 + 안내선).
- **자동 꺼짐**: 도착(`visiting`)하면 끈다. 다음 이동이 시작되면 다시 켠다.
- **끄기**: 안내 카드의 작은 [×] → 이번 구간 동안만 숨김 (다음 구간에서 다시 자동).
- **수동 켜기**: 머무는 중에도 미리 보고 싶으면 다음 일정 행의 작은 🧭 아이콘 버튼(또는 §2.2 작은 창의 [길 안내])으로 그 장소 안내.
  다른 장소를 골라 안내하면 안내 카드에 그 장소 이름.
- 지금의 큰 [길 안내] 버튼(`_NowSection`·`_BeforeFirst`, 52px)은 없앤다.
- 안내 중이면 **눈에 띄게**: 안내선은 굵은 primary + 흰 테두리, 나머지 구간은 옅게. 카메라는 내 위치 + 목적지가 들어오게 한 번 맞춤(이후 사용자가 움직이면 따라가지 않음).
- 위치가 없으면 안내 카드에 "위치를 켜면 길을 안내해요" (지금처럼 "{다음} 방향" 만 두지 않음).

### 2.2 지도에서 장소 누르기 → 작은 창
- 핀(오늘 일정 장소)을 누르면 핀 위에 작은 창: 번호·이름·예정 시각·상태(머무는 중/완료/예정) + **[설명 듣기]** **[길 안내]**.
  - [설명 듣기] → 가이드 노트(`t.onOpenGuide(placeId)`). 노트가 없으면 지금처럼 "지금 설명 듣기" 대체 동작.
  - [길 안내] → §2.1 수동 켜기.
  - 작은 글씨 링크 [자세히] → Map 탭에서 그 장소 시트 펼침 (유일하게 탭이 바뀌는 곳).
- 위험 구역을 누르면 지금처럼 설명.

### 2.3 아래 패널 — 남은 일정은 처음부터
- 여행 시작~첫 도착 전에도 **남은 일정 목록을 보여준다** (지금은 `total: true` 라 "오늘 일정 N곳 · 종료 예정" 한 줄만 — Figma 14-S2 를 따른 것인데 바꾼다).
  한 줄 요약은 목록 머리에 그대로 둔다.
- 남은 일정 행을 누르면 Map 으로 가지 않고 지도에서 그 핀을 강조 + §2.2 작은 창.
- [경로 전체] 버튼은 [전체 지도](작은 텍스트 버튼)로 바꾸고 Map 으로 보낸다.

## 3. Map

### 3.1 실제로 끄는 아래 시트
- 지금의 고정 카드(`_PlaceMapCard`, `_RouteSummary`)를 `DraggableScrollableSheet` 로 바꾼다. 멈춤 3단: 접힘(요약) · 반 · 펼침.
- **장소를 고르지 않았을 때**: 접힘 = "Day n 경로 · n곳 · 총 이동 n분" + [변경 내역], 반·펼침 = 그날 일정 목록(누르면 그 장소 선택).
- **장소를 골랐을 때**: 접힘 = 지금 카드 내용(제목·n/전체·시각·칩·[일정에서 보기][교체][삭제], 좌우로 넘기기 유지),
  펼침 = **일정 추가 화면과 같은 장소 상세** (사진·분류·주소·운영시간·휴무·요금·주차·메뉴·전화·소개 더 보기·현장 해설) — `place_search_sheet.dart` 의 `_PlaceDetail` 을 공용 위젯으로 꺼내 모달과 시트가 같이 쓴다.
  동행 중이고 일정 안 장소면 상세 위에 [설명 듣기].
- 관광지 레이어의 장소도 같은 시트로 (지금 모달 대신) — 푸터 [Day N에 추가] 유지.
- 지도 끌기와 시트 끌기가 충돌하지 않게 (시트 영역 밖은 지도).

### 3.2 동행 중 레이어
- 동행 중이면 Map 에도: 내 위치 점, 지나온 구간 회색, 지금 머무는 곳·다음 장소 강조. 데이터는 `TripController`(위치·상태)에서.
- 위험 구역은 Today 의 `t.zones` 와 같은 데이터를 쓰도록 맞춘다 (지금은 Map 이 따로 `api.avoid` 를 60초마다).
- 우회 카드 [이 길로 안내] → Today 로 돌아가 그 경로로 §2.1 안내 (지금은 토스트만).

## 4. 지켜야 할 것
- `PlanController` 는 Planner·Map·Today 가 함께 쓴다 (`select()` 는 `day` 도 바꾼다). Map 시트 선택이 Planner 강조를 망가뜨리지 않게.
- 테스트가 쓰는 키·찾기: `guide-card`, `eta-chip`, `bell-badge`, `demo-location-chip`, `offline-strip`, `trip-pill-time`, `today-location`,
  `find.byType(DraggableScrollableSheet)`, `Grabber().last` 끌기, 안내선 PolylineLayer 색·점 검사, `splitGuide`/`nearestIndex`, 문구 '첫 일정까지'·'여행 종료'·'남은 일정에 위험 신호'.
  바꿔야 하면 테스트도 같이 고치고 이유를 남긴다.
- fixture(`test/fixtures/*.json`, `test/support/trip_replay.dart`): API 호출이 늘면 `gw.unmatched` 기대가 깨질 수 있다.
- Figma 와 달라지는 곳(14-S2 한 줄 요약 → 목록, 큰 [길 안내] 버튼 제거, Map 시트)은 `docs/app/screens/` 해당 문서에 "2026-10-11 변경" 으로 적는다.

### 남은 문제
- **가이드 노트 없음 상태만 확인**: "데모 시작 상태로" 가 가이드 노트를 지우고, 노트 준비·[지금 설명 듣기] 는 LLM 호출이라 실제 스택에서는 17 의 "준비된 해설이 없어요" 까지만 봤다. 노트가 있을 때 [설명 듣기] → 본문은 fixture 테스트(f4)로만 확인.
- **"데모 시작 상태로" 는 빈 계획**을 만든다 (콘솔 문구도 "빈 계획"). 이번 확인은 일정 5곳을 API 로 넣어서 했다 — 대시보드만으로 Today 흐름을 보려면 일정까지 넣는 버튼이 필요할 수 있다 (콘솔은 이번 범위 밖이라 그대로 둠).
- 14-S2 "지금 위치에서 도보 n분" 은 처음 한 번만 계산해 걷는 동안 줄지 않는다 (예전부터). 안내 카드의 분·도착 예상은 갱신된다.
- Map 시트 접힘 높이는 내용별 고정값(경로 104 · 장소 카드 236 · 관광지 214 · 우회 300px + 위 버튼 칸 150)이다. 장소 카드에 위반 칩이 여러 줄이면 접힘에서 버튼이 아래로 밀려 살짝 끌어야 보인다.
- 지도 작은 창은 핀 위 248×196 고정. 화면 오른쪽 끝 핀이면 AI FAB·현재 위치 버튼과 겹칠 수 있다 (지도를 옮기면 해결, 자동으로 피하지는 않음).
- 우회 [이 길로 안내] → Today 안내는 fixture 테스트로만 확인 (실제 스택은 평상시 시나리오라 우회 카드가 뜨지 않음).
- Planner 의 [지도에서 보기] · 출발 토스트 [경로 보기] 는 그대로 Map 탭으로 간다 (Map 에 동행 레이어가 생겨 그대로 둠).
