## 데이터
| 무엇 | API |
|---|---|
| 두 일정 | ProposalDetail `before`, `after` (PlanDetail 스냅샷). 오늘(동행 중) 또는 카드가 바꾸는 날만. 동행 중이면 `done` 항목은 숨기고 "다녀온 곳 n곳" 한 줄 |
| 기존안 위험 | `GET /planner/plans/{id}/safety` (지금 일정) — 제안이 base_changed 가 아니면 before 와 같다 |
| 수정안 위험 | `POST /planner/plans/{id}/safety/preview {"ops": proposal.ops}` (새 항목 item_id 음수 → after 의 음수 id 와 매칭) |
| 지도 경로 | `POST /routing/route` 기존·수정 각각 (남은 구간, `hazards:"report"`) |
| 지표 | 위험한 곳 = 남은 visit 중 caution·danger 수 (null 은 세지 않음) · 규칙 위반 = 그날 `violations` 중 error 수 · 종료 = 그날 `end_at` · 이동 = 남은 `travel_minutes` 합 |

지표는 안전 변화가 있으면 "위험한 곳", 없고 위반 변화가 있으면 "규칙 위반"을 첫 칸에 둔다.

## 상태
- 안전 미리보기 503: 위험 배지 자리 회색 "확인 못 함", 지표 첫 칸을 규칙 위반으로.
- `base_changed=true`: 지도 위 Amber 띠 "제안 이후 일정이 바뀌었어요 · 적용 전에 확인해요" → [전체 적용] 시 409 → 36.
- 제안이 pending 이 아니면(이미 처리): 하단 버튼 대신 상태 줄("승인함"/"거절함"/"새 제안으로 대체됨").

## 동작
전체 적용·거절 = 19 와 같은 API. 닫기 → 대화로. 지도 Pin 탭 → 해당 행 하이라이트. 행 탭 → 지도 그 장소로.
