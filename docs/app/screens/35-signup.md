# 35 Signup — 가입 (P1)

Figma: 화면 `73:6173` · Spec `73:6237`

- **레이아웃**: 34 와 같은 필드 스타일 · "가입하기" 24 · "아이디와 비밀번호만 있으면 돼요" · 필드: 아이디 / 비밀번호(보기) / 이름(선택, placeholder "선택") · 각 필드 아래 규칙 안내 12(오류면 Danger) · [가입하고 시작하기].
- **API**: `POST /auth/signup {"login_id", "password", "display_name"?}` → 201 `TokenResponse` → 저장 → 02.
- **앱 검증(입력 중)** (account §3.1): 아이디 영문 소문자·숫자·`.`·`_`·`-` 4~32자, 영문·숫자로 시작 ("영문 소문자·숫자 4~32자") · 비밀번호 8~128자, 영문+숫자, 아이디와 다름 ("8자 이상, 영문과 숫자를 함께 써 주세요") · 이름 1~30자 ("구룡메이트가 부를 이름이에요. 비우면 아이디로 불러요").
- **서버 오류**: 409 `login_id_taken` → 아이디 "이미 쓰는 아이디예요" · 422 `weak_password` → 비밀번호 · 422 `invalid_request` → `errors[].loc` 필드.
- Google 계정과 아이디 계정은 별개다 (같은 이메일이어도). 안내는 하지 않는다.
