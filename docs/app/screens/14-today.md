# 14 Today — 동행 홈 (P0)

Figma: 화면 `73:2042` · Spec `72:844` · 상태 14-S1 `73:7222`(위치 꺼짐·오프라인), 14-S2 `73:7401`(첫 장소 전·데모 위치), 14-S3 `73:7529`(대화 밖 선제 알림) · 흐름 F3·F4

## 목적
여행 중 앱을 열면 가장 먼저 보는 화면. "지금 어디 있고, 다음은 뭐고, 늦었는지, 위험한 곳은 어딘지"를 한눈에. 지도(현재 위치·오늘 경로·위험 구역) + 지금/다음/남은 일정.

## 진입

### 패널
1. **지금** (`TripState.current`)
   - caption "지금 · HH:MM 도착" (`since` 또는 항목 `arrived_at`)
   - 장소명 17 Bold, 오른쪽 위험 배지(그 visit 의 `risk`)
   - "머무는 중 · {end_at}까지 예정 (n분 남음)" — n = end_at − now. 넘었으면 "예정보다 n분 더 머무는 중"(Amber)
   - [✨ 이야기 듣기](AI Soft) → 17 (가이드 노트) / [길 안내](Secondary) → 15
2. **다음** (`TripState.next`)
   - 번호 원 28 · 장소명 16 Bold · "{planned_start} 예정 · {수단} n분"
   - ETA 칩: `delay_minutes` ≤ 0 → Green "제시간"(0) / "n분 여유"(<0) · 1 이상이고 오늘 새 위반 없음 → Amber "n분 늦음" · 새 위반이 생긴 상태(오늘 `delay` 이벤트가 pending 제안과 함께 있음) → Red "18:07 종료 · 규칙 넘음"
3. **남은 일정** — "남은 일정 n곳 · {마지막 end_at} 종료 예정" + "전체 일정 ›"(→ Planner 탭) · 행: 시작 시각 · 장소명 · 위험 배지
4. (맨 아래, 스크롤) 텍스트 버튼 "여행 종료" → 확인 다이얼로그 → 30

## 엣지
- `out_of_order` 도착(순서 건너뜀): "지금"은 도착한 곳, "다음"은 서버 `next` 그대로. 건너뛴 앞 항목은 회색 "지나침"이 아니라 그대로 planned 로 둔다(일정 변경은 제안으로).
- 서버 시각이 가상 시각(clock="sim")이면 Pill 시각 옆에 작은 "가상" 표시는 하지 않는다(발표 화면). 33 에서만 보인다.
