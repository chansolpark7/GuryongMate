# 23 Hazard Alert — 위험 구역 접근 긴급 경고 (P0, 장면 ④ 보조)

Figma: 화면 `73:3810` · Spec `73:3945` · 컴포넌트 "Hazard Alert"(Expanded·Collapsed) · 흐름 F7 `73:8607`

## 목적
지금 위치가 위험 구역(침수 감시·방파제) 안이거나 50m 안이면 **LLM 없이 즉시, 가장 눈에 띄게** 알린다.

## 진입
`near_hazard` 이벤트 (level 1). 대부분 위치 전송 응답 `events` 로 온다 → 폴링을 기다리지 않고 바로 띄운다. 어떤 탭·시트·다이얼로그 위에서도 **최상단**.

## 레이아웃
| 구역 | 내용 |
|---|---|
| 경고 패널 | 0–236 전체 폭, Danger #E5484D, 하단 r24, 그림자 0 8 24 rgba(229,72,77,.35). 상태바 아이콘 흰색 |
| 아이콘 | 44 원 흰색 20% + alert 28 흰색 |
| 제목 | 20 Bold 흰색 — 구역 종류에 따라 "침수 감시 구역 근처예요" / "방파제 근처예요" |
| 본문 | 15 흰색 — 서버 `message` 의 구역·행동 지침 ("구룡포수협 주변 · 물이 고인 길은 피하세요") |
| 근거 | 12 #FFD7D8 — "수위 센서 실측 · 위험 (등급 3) · HH:MM" (구역 reason) |
| 버튼 | [피해 가는 길 보기] 흰 바탕 Red 글자 · [확인] 흰색 20% |
| 지도 | 그 구역 Red 강조 + 현재 위치 |

## 데이터
- `message` (서버 고정 문구) — 본문에 그대로.
- 구역 이름·종류·reason: `payload` (필드 미정 → [gaps](../gaps.md) b2). 없으면 `GET /safety/avoid` zones 중 현재 위치에 가장 가까운 구역의 `name`, `kind`, `risk`, `reason`.

## 동작
| 동작 | 결과 |
|---|---|
| 피해 가는 길 보기 | `POST /routing/route {"mode":"walk","stops":[현재, 다음 장소],"hazards":"avoid","steps":true}` → 28 (우회 카드) |
| 확인 | 패널이 **Collapsed strip**(32 높이 Red 띠 "위험 구역 근처 · {구역}")으로 접혀 상단에 남는다. 다음 위치에서 구역을 벗어나면 사라진다 |
| 뜨는 순간 | 진동(heavy) 1회 + 시스템 알림음 1회. 같은 구역에서 다시 울리지 않는다(서버 중복 억제 + 앱: 같은 event id 무시) |
| 이벤트 seen | 패널이 보이면 `POST …/events/{id}/seen` |

## 규칙
- AI(Purple)를 쓰지 않는다 — 판단이 실측·규칙이다. 대안 상의는 사용자가 원할 때 FAB.
- Danger Red 는 이 경고와 위험 배지에만 쓴다.
- 데모 위치 모드에서도 똑같이 뜬다 (위치는 서버에 들어온 위치).
