# 16 Arrival Docent — 도착 해설 카드 (P0)

Figma: 화면 `73:2418` · Spec `72:1259` · 상태 16-S1 `73:7767`(노트 없음 → 즉석 생성) · 컴포넌트 "Docent Arrival Card" (Components_Companion) · 흐름 F4

## 목적
장면 ②의 시작. 도착하면 LLM 없이 바로 "이야기 들어볼까요? [짧게] [자세히]" — 사용자 취향(메모리 style)에 맞는 쪽을 강조한다.

## 진입
`arrived` 이벤트 (level 0+2, `card: {kind:"docent", place_id, item_id}`). Today·Planner·Map 어느 탭이든 하단(패널/탭 위)에 뜬다. AI 시트가 열려 있으면 시트 안 대화 맨 아래에 같은 카드를 넣는다(대화 기록에는 남지 않는 로컬 카드).

## 데이터
| 필드 | 출처 |
|---|---|
| 장소명 | PlanDetail 의 그 item `place.title` |
| 준비 상태 | `GET /docent/plans/{plan_id}/notes/{place_id}` → `status` (ready·stale = "가이드 준비됨") |
| 선호 | `GET /docent/memory?plan_id=` 에서 `category:"style"` 항목. 길이 선호 판단은 앱 규칙: 문구에 "짧"/"핵심" → short, "자세"/"길게" → long (메모리는 자유 문장이라 판단 필드가 없음 — 서버가 `style_length` 같은 요약을 주면 그것을 쓴다) |

## 상태
| 상태 | 표시 |
|---|---|
| ready / stale | 위 레이아웃 (stale 도 그대로, 현장은 빠름 우선 — docent §3.2) |
| pending / preparing | caption "가이드를 준비하고 있어요" + 버튼 대신 [지금 설명 듣기] |
| failed / 없음 — 16-S1 | caption "가이드 없음" + [✨ 지금 설명 듣기] + "준비된 해설이 없어 10초쯤 걸려요" |
| 노트 조회 실패 | 버튼은 그대로, 누르면 17 이 오류 처리 |

## 엣지
- 같은 장소를 다시 도착(나갔다 들어옴): 서버 중복 억제를 따른다. 카드가 다시 오면 그대로 보여준다.
- 3단계 이벤트가 오면 카드는 칩으로 접힌다 (events.md §2).
