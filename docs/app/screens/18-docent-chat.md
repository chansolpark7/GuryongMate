## 목적

## 레이아웃
05 AI 시트 Full(top 56). 헤더 컨텍스트 "{장소명} · 현장 해설" (TripState.current 가 visiting 이면, 아니면 "{계획명} · 동행 중").
대화 흐름(위→아래, 간격 14): 사용자 말풍선 → 단계 요약(접힘, `steps_done.summary`) → 답변 15/22 → 출처 칩(가능할 때) → 사용자 "더 짧게 해줘요" → 답변 → **메모리 칩** → 후속 칩 → Input.

## 데이터·API
| 무엇 | API |
|---|---|
| 전송 | `POST /agent/sessions/{sid}/chat {"message"}` SSE (`status`·`step`·`text`·`steps_done`·`done`) |
| 메모리 칩 판단 | (1) `step` 중 메모리 저장 단계가 오면 — kind·title 미정 → [gaps](../gaps.md) b4 · (2) 대안: 턴 시작 전 `memory_version` 을 기억하고 `done` 뒤 `GET /docent/memory?plan_id=` 를 다시 읽어 오르면, 새로 생긴/바뀐 항목의 text 로 칩 |
| 출처 칩 | 지금 SSE 에 출처가 없다 → 숨김 (gaps b6) |

## 상태
- 응답 중: Input 의 보내기 버튼이 Stop(검정), 후속 칩 비활성. 409 `agent_busy` 스낵바.
- 오류 `error` 이벤트: 답변 자리에 회색 문구 + [다시 시도] (같은 메시지 재전송).
