# 11 Trip Start — 여행 시작 확인 (P0)

Figma: 화면 `73:1486` · Spec `72:278` · 흐름 F3 `73:8263`

## 목적
여행일에 계획 모드 → 동행 모드로 넘어가는 유일한 문. "시작해도 일정은 그대로"라는 안심과, 시작하면 무엇을 해 주는지를 한 장에 보여준다.

## 진입
- 오늘이 여행일(`start_date` ≤ 오늘 ≤ `end_date`, 오늘 = 서버 시각 기준 — `GET /trip/plans/{id}/state` 의 `now`)이고, (첫 일정 `start_at` 1시간 전 이후 **또는** 현재 위치가 구룡포 반경 3km 안)일 때 계획 화면(04/25)에 들어오면 **그날 한 번** 자동으로 뜬다. 닫으면(나중에) 그날은 다시 자동으로 뜨지 않는다(로컬 기록).
- 직접 열기: 29 계획 카드 [오늘 여행 시작], Planner ⋯ "여행 시작".
- 자동으로 시작하지 않는다 (trip §1.2 — 여행일에 집에서 계획만 고치는 경우).

## 데이터
- PlanSummary: `title`, `start_date`, `day_start`, `day_end`, `item_count` (오늘 항목 수는 PlanDetail `days[day].items` 중 skipped 제외)
- 가이드 준비 상태: `GET /docent/plans/{plan_id}/notes` (status ≠ ready/stale 개수)

## 엣지 케이스
- 세션이 없으면 `session_id` 를 생략한다(서버가 만든다).
- 다른 계획이 진행 중이면 서버가 이전 것을 끝낸다. 앱은 29 목록의 여행 중 카드가 바뀐다.
- 여러 날 여행의 2일차: 제목 아래에 "2일차" 를 덧붙인다 (`TripState.day`).
