## 1. 이름과 표기

- 사용자에게 보이는 이름: **구룡메이트**. 앱 이름, 로그인 화면, AI 시트 헤더, Agent 페르소나 이름이 모두 "구룡메이트"다 (AI 가 자기를 부를 때도 같다).
- 코드·영문 표기: **GuryongMate** (패키지명, 클래스 접두사, 영문 문서).
- Figma 의 "Planit", 기존 앱의 `MaterialApp(title: 'Planit')`, AI 시트의 "AI Planner" 는 초기 임시 이름이다. 쓰지 않는다 → [gaps.md](gaps.md) (c).
- 포지셔닝: "여행을 계획하는 AI"가 아니라 **"여행을 함께 수행하는 AI"**. 화면 문구도 "만들어 드려요"보다 "함께 / 먼저 알려드려요 / 현장에서" 쪽을 쓴다.

## 3. 계획 모드 / 동행 모드

### 3.1 모드는 상태다 (`docs/trip/README.md` §1)
- **동행 모드 = 계획 모드 + 추가 기능.** 동행 중에도 일정 편집·AI 대화가 모두 된다. 실수로 켜져도 잃는 기능이 없다.
- 계획 화면에 들어올 때 `GET /trip/plans/{id}/state` 를 부르고 `active=true` 면 동행 모드로 그린다. 스위치가 아니다.
- 여행일은 하루 단위. 여러 날 여행은 날마다 시작한다.

### 3.2 전환 규칙

| 상황 | 앱 동작 | 화면 |
|---|---|---|
| 오늘이 여행일이고 (첫 일정 1시간 전 이후 또는 구룡포 3km 안) | 계획 화면 진입 시 한 번 "오늘 여행 시작할까요?" (자동 시작 안 함). Plan List 카드·Planner 상단에도 [오늘 여행 시작] | 11 |
| [여행 시작] | `POST /trip/plans/{id}/start {session_id}` → 동행 모드 | 11 → (13) → 14 |
| 409 `not_trip_day` | "일정은 10/10이에요. 오늘로 옮길까요?" → 옮기기 = AI 제안(날짜 변경) → 승인 후 다시 start | 12 |
| 위치 권한 없음 | 권한 안내 → 허용/거부(거부해도 시작은 된다) | 13 |
| 실수로 시작 | 패널 맨 아래·Planner ⋯ [여행 종료] → `POST …/end`. 진행 기록 외에는 바뀐 것이 없다 | 30 |
| 사용자가 끝냄 | 확인 다이얼로그 → end → 하루 요약 | 30 |
| 자동 종료 (`ended_reason: auto`, 마지막 일정 + 120분 또는 자정) | 다음에 앱을 열 때 state 가 inactive → 계획 모드로 그리고 하루 요약을 한 번 보여준다 | 30 |

### 3.3 모드별 차이

| | 계획 모드 | 동행 모드 |
|---|---|---|
| 하단 탭 | Planner · Map | **Today** · Planner · Map (Today 가 기본) |
| AI 시트 헤더 컨텍스트 | "계획명 · Day n" | "계획명 · 동행 중" (Agent 가 현재 상황 블록을 씀) |
| 위치 | 안 보냄 | 화면이 켜진 동안 30m/30~60초마다 전송 (데모 위치 모드면 안 보냄) |
| 이벤트 폴링 | 안 함 | 5~10초 ([events.md](events.md) §5) |
| 타임라인 카드 | 위험 배지 | + 다녀옴(✓)·지금 여기·실제 시각 |
| 안전 | 계획 화면 배지·배너 (planner 경고) | + AI 선제 제안, 위험 구역 즉시 경고 |

- **스택**: 목록 → 계획(Shell) → 상세 화면(push). 탭 전환은 상태를 유지한다(IndexedStack, 기존과 같음).

- **전역 오버레이**: 16(도착 카드)·23(위험 경고)은 어떤 탭·시트 위에서도 뜬다. 23 이 항상 최상단.

## 6. 공통 규칙

### 6.1 데모 데이터 (모든 예시 화면 공통)
페르소나 서윤(29) + 어머니. 계획 "엄마랑 구룡포" 10/10(토) 12:30~18:00, 규칙 `end_before 18:00 (hard)`.
일정: ① 구룡포 일본인 가옥거리 12:30 → ② 구룡포항(점심) 13:38 → ③ 구룡포과메기문화관 14:48 → ④ 북방파제 16:00 → ⑤ 바다뷰 카페 16:47(차량).
- 장면 ② 12:32 가옥거리 도착 → 해설 → "더 짧게".
- 장면 ③ 14:00 가옥거리에서 30분 더 머묾 → 카페 종료 18:07 (`day_overflow` + 규칙 위반) → 선제 제안(과메기문화관 빼기) → "과메기문화관은 유지해줘" → 카페 빼고 구룡포항 45분 → 16:55 종료 → 승인.
- 장면 ④ 15:20 북방파제 16:15 주의→위험 (풍속 15m/s·파고 3.2m 예보) → 근대문화역사관(실내)으로 교체 → 비교 → 승인. 16:05 이동 중 구룡포수협 주변 침수 감시 구역 접근 경고.

### 6.2 색·카피
- Foundations 토큰 그대로 (`lib/core/theme/app_theme.dart`). **AI 요소에만 Purple.** 위험 단계 색(Green/Amber/Red)은 안전 의미에만. `risk=null` 은 회색 "판단 불가"이고 절대 Green 으로 그리지 않는다.
- 함수명·API·센서 코드 노출 금지. 결과 요약을 사람 말로 ("파고 3.2m 예보", "수위 센서 실측 · 위험").
- 예보는 단정하지 않는다 ("~예보", "바뀔 수 있어요").
- safety 의 `advice`·`guidance` 는 LLM 지시문이라 화면에 그대로 쓰지 않는다. 화면은 `hazards`·`better_times` 로 직접 만든다.

### 6.3 로딩 · 빈 상태 · 오류 (Figma `States_Feedback` `73:7102`)

| 상황 | 표현 |
|---|---|
| 첫 로딩 | 스켈레톤 (#E8EBEF, 1.2s shimmer). 300ms 안에 끝나면 보이지 않게 지연 표시 |
| 다시 불러오기 | 기존 내용 유지 + 상단 얇은 진행 표시 |
| 빈 상태 | 아이콘 32 + 제목 + 다음 행동 버튼 ("일정 추가" / "AI로 만들기") |
| 503 `upstream_unavailable` (agent), `places_unavailable`·`safety_unavailable` (planner), 게이트웨이 502 | 화면 단위면 오류 뷰 "서버에 연결하지 못했어요 · 다시 시도" / 부분(안전 배지 등)이면 그 자리만 비우고 한 줄 안내. **일정은 그대로**임을 말한다 |
| 409 `agent_busy` | 스낵바 "구룡메이트가 답하는 중이에요. 잠시 후 다시 눌러 주세요". 입력·카드 버튼은 응답 중에 미리 비활성 |
| 409 `base_changed` | 36 확인창 |
| 409 `proposal_not_pending` | 카드를 서버 상태로 다시 그림 (GET 세션) + 스낵바 "이미 처리된 제안이에요" |
| 401 `unauthorized` | `POST /auth/refresh` 한 번 → 원래 요청 재시도 → 또 401 이면 01 |
| 오프라인 | 상단 Dark 띠 "오프라인 · 연결되면 다시 불러올게요". 동행 중이면 위치를 모아 두었다가 `{points:[…]}`로 보낸다 |
| 422 | 입력 화면이면 필드 오류, 아니면 버그로 보고 일반 오류 문구 |

### 6.4 피드백 수단 고르기

| 수단 | 언제 | 예 |
|---|---|---|
| **상태 갱신만** | 사용자가 할 일이 없는 변화 | 도착 표시, ETA·지연 분, 진행 상태 (0단계) |
| **토스트**(스낵바, 4초) | 지나가도 되는 알림, 되돌리기 | 출발 → 다음 장소, 안전 완화, 적용 + 실행 취소, agent_busy |
| **상단 배너** | 화면에 머무는 동안 계속 유효한 상태 | 안전 경고(Context Banner), 위치 꺼짐, 오프라인 |
| **카드** | 사용자가 고를 행동이 있는 알림 | 도착 해설 카드(16) |
| **AI 대화 메시지** | AI 가 판단·대안을 말해야 할 때 (3단계) | 지연·안전 선제 제안(19, 22) |
| **시트** | 하던 화면 위에서 잠깐 보는 상세 | 위험 근거(26), 전망(27), 여행 시작(11) |
| **다이얼로그** | 되돌리기 어려운 결정 | 여행 종료, 계정 삭제, 메모리 모두 지우기, base_changed |
| **긴급 패널** | 안전에 바로 영향 | 위험 구역 접근(23) — 최상단, 진동 |

### 6.5 인증·주소
- 모든 요청 `Authorization: Bearer <access>` (account). `X-User-Id` 는 개발 모드 전용이고 앱은 보내지 않는다.
- 게이트웨이 주소 하나 (`설정 > 서버 주소`). 서비스 경로 `/auth` `/users` `/places` `/planner` `/agent` `/safety` `/routing` `/trip` `/docent`.
