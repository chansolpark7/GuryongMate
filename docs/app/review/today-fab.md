# Today AI·현재 위치 버튼이 패널을 따라 움직인다 (feat/today-fab, 2026-10-12)

Map 탭처럼 Today 의 오른쪽 버튼(현재 위치 · AI)이 아래 패널 위 가장자리에 붙어 함께 움직인다.

| 캡처 | 패널 | 버튼 |
|---|---|---|
| `today-fab/01-collapsed-019.jpg` | 접힘 0.19 | 패널 위 12px, 함께 내려감 |
| `today-fab/02-half-049.jpg` | 반 0.49 (처음) | 패널 위 12px |
| `today-fab/03-full-086.jpg` | 펼침 0.86 | 숨김 (투명 + 눌리지 않음) |

캡처: 로컬 스택 + `deploy/build_web.sh` 웹 빌드, 390×844, 로컬 테스트 계정에 관제 [데모 계획으로 시작] 과 같은 순서(`reset.js` demoPlanStart)로 계획을 만들고 [오늘 여행 시작] → [여행 시작] (10/10 12:20, 첫 일정 전).

## 바뀐 것

- **버튼 자리** (`today_screen.dart`): 화면 위 고정(`top + 222`) → 패널 높이(`DraggableScrollableNotification.extent`)를 `ValueNotifier` 로 듣고 `bottom = 패널 위 − 12` 로 계산.
  Map 처럼 시트 builder 안에 '떠 있는 띠'를 넣으면 패널 비율(0.19·0.49·0.86)이 띠 높이만큼 바뀌어서, 비율은 그대로 두고 위치만 계산하는 쪽을 골랐다.
  패널을 끄는 동안 다시 그리는 것은 버튼·작은 창뿐 (지도 전체를 다시 그리지 않음).
- **순서·모양**: Map 과 같게 위치 버튼(44) 위 · 10 · AI(56) 아래. 둥근 버튼은 Map 과 같은 그림자·아이콘 20 (알림 종 버튼도 같은 위젯이라 함께 바뀜).
- **숨김**: 패널이 0.6 을 넘으면(0.86 쪽) 또는 버튼 위 끝이 위 막대(Pill·데모 칩·안내 카드) 아래 끝보다 올라가면 투명 + `IgnorePointer`. 0.19·0.49 에서는 보인다. 제안 점(hasSuggestion)은 그대로.
- **작은 창 피하기** (`_fabRect`): 버튼의 실제 칸(숨으면 없음). 패널 높이가 바뀌면 작은 창 자리를 다시 고른다.
- **도착 카드·미리보기·토스트** (`trip_overlay.dart`): Today 가 `TripController.todayChrome`(위 막대 아래 y · 버튼 칸)을 알리고 오버레이가 그것을 보고 자리를 잡는다.
  - 처음 생각(고정 자리 `top+226` 에서 전체 폭)은 **겹친다**: 390×844 에서 패널 0.49 의 버튼 칸이 y≈272~382, 도착 카드가 y≈226~288 이라 전체 폭이면 AI 버튼을 가린다.
  - 그래서 버튼과 함께 움직이게: 버튼 바로 위 **전체 폭** (토스트가 맨 아래, 도착 카드는 그 위). 위 막대까지 자리가 모자라면 도착 카드는 버튼 왼쪽 칸,
    버튼이 숨으면(0.86) 위 막대 바로 아래 전체 폭. 미리보기(AI 말풍선, 폭 232)는 AI 버튼 왼쪽에 아래 끝을 맞춘다.
  - 다른 탭·push 화면 자리는 그대로.

## 테스트

- 키·문구 유지 (`today-location`, `guide-card`, `today-place-popup` 등). 버튼 칸에 `today-fab` 키를 새로 붙였다.
- `today_map_test` '14 작은 창 …': 버튼 칸을 `Column` 조상 대신 `today-fab` 키로 찾게 바꿈 (버튼 순서가 바뀌어 가장 가까운 Column 이 달라질 수 있어서). 기대값은 그대로.
- 새 테스트 `today_map_test` '14 AI·현재 위치 버튼 …': 0.49 에서 패널 위 12px · 위치 위/AI 아래 · 도착 카드 전체 폭이고 버튼과 안 겹침 → 0.19 에서 150px 넘게 내려가고 패널 위 12px · 작은 창이 버튼과 안 겹침 → 0.86 에서 투명·hitTestable 없음·`todayChrome.fab == null` → 0.49 로 돌아오면 다시 보임.
