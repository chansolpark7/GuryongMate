# outline — 본선 발표 슬라이드 구성 (초안)

> 대회: 2026 디지털 트윈 AI Agent 해커톤 본선, **2026-10-13**. 서비스 이름: **구룡메이트** (코드·영문 GuryongMate).
> 발표는 **실제 UI 데모 중심**(기능 → 조작 → 결과 화면). 데모 대본은 [demo_script.md](demo_script.md), 구조도는 [architecture.md](architecture.md),
> 숫자는 [facts.md](facts.md) 에 있는 것만, 예상 질문은 [qa.md](qa.md).
> **발표 시간은 저장소 문서에 없다.** 아래 시간은 10분 발표 기준 가정이다 — 배정이 정해지면 데모(4장)는 줄이지 말고 나머지를 줄인다 (§3).

## 1. 흐름

```
문제 → 해결(동행 AI) → 데모 4장면 → DT 데이터 활용(가공·해석 → 행동) → 기술 구조 → 실현 가능성 → 차별점·확장성
```
